# 菜单栏应用：实现前确定的端到端验收

| 场景/失败方式 | 预期行为 |
| --- | --- |
| 启动已打包 .app | macOS 顶部出现网格图标；参数窗口可打开；不依赖终端当前目录 |
| 关闭参数窗口 | 菜单栏图标保留，可再次打开；显式退出才结束程序 |
| 手动价格、百分比区间、600 USDT | 表单调用包内 Rust 程序，显示与 CLI 一致的 3 格 / 131.81 / SL 73332 / TP 95172 |
| 联网 / 手动切换 | 只发送当前模式需要的参数，不把旧 ATR、手动区间或参考价混入联网请求 |
| 修改表单、重新生成 | 清除旧方案，避免把旧线位当成新输入的结果；请求期间表单禁用 |
| 空白、非法数字、未知交易对、资金不足 | 可见错误，不显示看似成功的旧结果 |
| 启用 HTTP 代理 | 所有公开 GET 经代理；代理接收绝对 URL；不携带 API Key |
| 启用 SOCKS5 代理 | 使用远程 DNS 的 socks5h；不让目标域名在本机解析后绕过代理 |
| 代理格式/端口错误 | 生成前或 CLI 参数验证时给出错误 |
| 代理无法连接或被拒绝 | 报错，不自动绕过指定代理直连 |
| 不启用代理或离线计算 | 不发送手填代理参数，旧 CLI 和离线行为保持兼容 |
| 取消生成、退出应用 | 终止当前计算子进程，过时结果不能重新填入窗口 |
| Rust 程序缺失/失败、JSON 异常 | 可见错误，不崩溃、不冻结界面 |
| 输出超过 Pipe 缓冲区 | 用临时文件接收输出，避免等进程结束和等缓冲释放互相阻塞 |
| 保存输入、重启应用 | 恢复输入和代理设置；不自动联网、不自动生成交易方案 |
| 复制/导出 | 用户点击后才写剪贴板/文件；导出有效 JSON；取消保存不写文件 |

检查包括 Rust CLI 的代理端到端测试、原生 .app 构建/签名检查和实际 GUI 操作。不会创建真实交易机器人。

## 历史行情：实现前确定的失败情景

| 场景/失败方式 | 预期行为 |
| --- | --- |
| 单独获取历史 BTC 行情，本金或手动价格未填写 | 仍可通过公开 API 获取已收盘 OHLC、现价与 ATR，不读取本地 CSV |
| 选择周期、历史根数和 ATR 周期 | 请求与表单一致；默认 180 根日线；历史根数须大于 ATR 周期且不超过 1000 |
| 末根尚未收盘，含极端价格 | 从历史曲线、导出和 ATR 计算中排除，不让波动估计被未收盘数据污染 |
| 选择最多 1000 根 | 请求截止于当前 UTC K 线之前，正常返回 1000 根已收盘数据，而不是混入一根实时线 |
| 上市时间短、API 返回的根数少于请求 | 保留真实样本数量并显示提醒；不足 ATR 所需样本时明确失败 |
| K 线重复、漏根、OHLC 非法、HTTP 错误 | 报错；不退回 demo、旧结果或手动 ATR |
| 历史获取时启用 HTTP / SOCKS5h 代理 | 全部公开请求走同一个代理；代理失败不得直连回退 |
| 联网生成网格方案 | 同时获取所选历史样本；ATR 模式使用这些真实已收盘数据计算线位 |
| 改本金等资金参数 | 清除旧方案，已获取的历史数据可继续查看 |
| 改交易对、周期、根数、ATR 周期或代理 | 清除失效的历史快照，防止把上一组数据作为新输入的依据 |
| 请求取消或中途修改设置 | 终止子进程，迟到历史数据不能覆盖当前状态 |
| 导出历史 JSON | 保留来源地址、获取时间、样本数量、ATR 与完整 OHLC，方便复算 |

验证方式为真实 CLI + 本地 HTTP/代理服务，以及 Swift 表单 → 包内 Rust 进程的端到端测试。上线行情另做只读烟雾验证；GUI 的图表显示与按钮操作需区分于桥接测试。

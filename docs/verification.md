# 编码前确定的失败场景与端到端验收

测试只调用真实编译后的命令行程序，不调用计算函数。联网路径使用本地 HTTP 服务提供确定的数据，不依赖真实交易所，也不下单。

| 场景 | 预期行为 |
| --- | --- |
| 600 USDT、参考价格 84000、默认百分比区间 | 输出 75600 / 92400，止损 73332，止盈 95172；格数至少 2；N 格对应 N+1 个严格递增价格 |
| 逐格手续费 | 使用币安等比网格公式，单边费率只收买卖各一次；校验取整后的最差一格 |
| 风险预算比可投入本金小 | 自动缩小投入；单边下跌止损情景亏损不超过账户风险预算 |
| 数量和价格精度较粗 | 数量向下取整；资金/风险不超限；每个价格有效；重复价位不能输出 |
| 本金过低、手续费过高、最低订单金额过高 | 明确说明无可行方案；不能强制凑两格 |
| 固定格数不能满足约束 | 失败并给出原因，不能偷偷替换用户格数 |
| 非有限数、零/负资金、风险百分比错误 | 失败退出，不输出 NaN、Infinity 或误导性参数 |
| 区间倒置、参考价格在区间外、SL/TP 不在区间外 | 失败退出 |
| 配置错别字、未知字段、文件缺失 | 失败退出；CLI 显式输入覆盖 TOML；相对 K 线路径以配置目录为基准 |
| ATR 没有数据、数据不足、零波动 | 失败退出 |
| OHLC 非法、时间倒序/重复/缺少周期 | 失败退出，不在错误数据上计算 ATR |
| 手动 ATR 与 K 线输入冲突 | 失败退出，避免来源歧义 |
| 公开 API 正常响应 | 使用返回的价格和过滤规则，排除未收盘 K 线，标明数据来源和周期 |
| API HTTP 错误、返回异常、缺少必需过滤规则 | 失败退出，不悄悄改用离线默认值 |
| JSON 导出 / 交互输入 | JSON 可解析，提示不污染 JSON；导出结果与标准输出一致；EOF 不会死循环 |

止损情景只模拟从启动价单边下跌，包含建仓、下方买单、手续费预留和假设滑点；不是任何行情下的最大亏损保证。另算跌穿止损 5% 的压力情景。

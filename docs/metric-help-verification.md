# 新手指标说明 toast

## 实现前验收与失败场景

- 结果指标、价格卡片、历史指标和左侧所有输入字段都有说明入口，不能只解释 A/B。
- 点击问号只显示解释，不修改表单、切换策略或发出行情请求；键盘也能触发。
- B 的入口明确说明自动激活条件，区分「未激活」与「没有持币」，不提供强制开关。
- 说明明确百分比与百分点、负收益与负评分、4h 的根数与天数、网格卖出与完整往返的区别。
- toast 固定在窗口上层，不随长列表滚走；可以关闭，默认自动消失，鼠标停留时暂停计时。
- 快速连续点击时只显示最新说明，旧提示的定时器不能关掉新提示。
- 说明文字可选择复制，读屏可读，按钮有明确名称；不影响输入框及现有复制/导出。
- 复用真实桌面桥接 E2E 验证说明与生产字段、后端输出配合；另做实际窗口点击验收。

## 实现

- 词典位于 `desktop/macos/MetricGuide.swift`，全部生产输入字段和固定结果指标均有逐项说明，动态 ATR 标签也复用同一说明。
- `MetricHelpLabel` 统一复用问号入口，支持鼠标/键盘；`MetricHelpToast` 固定在窗口右下方、底部操作栏上方。
- 每次提示有独立 UUID，连续切换会取消旧等待，并在关闭前核对身份。鼠标停留暂停计时，离开后重新等待 12 秒；支持关闭按钮与 Esc。
- A/B 组新增「B 如何激活？」和「趋势底仓」入口，说明 20/60 根均价、当前 K 线周期、初始卖格半数向下取整、未激活含义，以及这只是回测而非实盘开关。
- 本次未修改后端策略、收益算法、自动激活条件或用户草稿默认值。

## 验收结果与边界

16 项桌面桥接 E2E 通过，包括真实表单 → 后端 → JSON、说明覆盖全部 FieldID、B 激活规则解释、动态 ATR 标签，以及查看说明前后方案一致。静态核对确认所有结果 `metric()` 标签均能找到说明。完整 macOS 原生编译、应用打包及本地签名校验通过，`git diff --check` 通过。

实际窗口点击验收未完成：Cua 连接新应用时返回 `Sky Computer Use native pipe closed before response`，系统日志存在 `SkyComputerUseService-2026-10-19-185534.ips` 崩溃记录；之后按 bundle ID 连接提示存在多个同标识应用。因而没有把 toast 实际显示、定时关闭或鼠标/键盘交互描述为已通过 GUI 验收。这不影响已完成的源码、编译及桥接验收。

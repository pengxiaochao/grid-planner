# 压力预算、细周期回放与滚动样本外验收

## 实现前失败清单

1. 数量只按正常 SL 缩放，压力损失超过预算：按配置的压力成交价约束数量，取整后同时复核两种损失；最小订单不满足就明确失败。
2. 分位取整、费用储备、零压力和高压力导致漏算：独立复算全库存压力损失；储备已含在投入中，不再额外加到本金。
3. 资金口径不清：启动网格购币成本 + 下方买单现金 + 储备币购入成本 = 总投入；总投入 + 未分配 = 允许投入上限。
4. 细周期漏根、区间不足、周期过粗、未收盘或 OHLC 聚合不一致：拒绝，不静默退回日线；细周期只替换成交路径，ATR 和选参时间界限仍用原周期。
5. 联网细周期超过单次 1000 根：按时间分页，检查推进、连续性、全部覆盖和聚合一致性；不把最近 1000 根当作全历史。
6. 偷看未来：每个滚动窗口独立用此前数据重新选参；后续价格不能改变早期窗口参数；不可行窗口保留错误，不按零收益参与汇总。
7. 用收益差代替风险：A、B 分别显示相对同额持有的超额收益，同时保留回撤、成本与观望判定；超额收益不单独决定是否通过。
8. 把发展评分当样本外评分：界面和文档说明发展段参与选参，最终检验未参与选参；多段指标独立建仓，不伪造连续复利净值。

先编写真实 CLI/桌面桥接 E2E，再实现。细周期仍无法证明限价排队、部分成交和实盘滑点。压力约束只保证指定模型情景，不保证真实最大损失。

## 修正后的口径

原截图的 −7.41 是参与选参的三段发展评分，不是夏普或样本外评分。公式为：发展段平均本金收益 − 各段最大回撤的最大值 − 各段收益标准差 + 最差一段双倍成本收益。最终 36 根没有参与这项排名；其 2.88% 是最终检验回撤。旧报告同段持有回撤已于 A/B 实验中补全为 8.56%，所以不能仅凭 4.62% < 5.84% 断言风险调整后更差。

指定压力成交价 `X = SL × (1 − stress_pct/100)`，费用、库存及储备币一并计入压力亏损。用压力损失反推每格数量后，数量向下按 stepSize 取整、投入向上到分，最后再次验证 `max(正常 SL 损失, 压力损失) <= 风险预算`。不再把超预算压力值仅作为展示。预算太低、压力过高或订单门槛过大时直接不可行；更严重的真实跳空仍可突破此模型约束。

## 日线 ATR + 真实小时回放验收

2026-10-19 从公开 API 获取 180 根已收盘日线及覆盖同一区间的 4320 根小时线；小时线分五页读取，聚合后与日线 OHLC 一致。维持资金/风险/16 格设置，按新风控和小时成交路径重新选参，区间选为 3 ATR。最终检验为 2026-09-13 至 2026-10-18 的 36 根已收盘日线，对应 864 根小时线。

| 策略 | 本金净收益 | 最大回撤 | 双倍成本净收益 |
| --- | --- | --- | --- |
| A 原网格 | 3.20% | 2.81% | 2.81% |
| B 趋势底仓 | 4.15% | 2.81% | 3.76% |
| 同额持有 | 5.69% | 8.37% | 5.39% |

A 相对持有 −2.49 个百分点，B 相对持有 −1.54 个百分点。B 在本段较 A 高 0.95 个百分点，仍不能据此自动推广。发展评分 −8.00，依旧 `wait`，界面复制填写被禁用。本次当前参考价为 82236.84，当前投入 650.64、压力损失 93.72，均与“保留原 4.5 ATR 线位单独缩仓”的算例区别列示。新旧收益同时受到风险模型、成交周期、选参结果影响，不能把收益变化全部归因为 B 的改进。

独立滚动检验使用训练前缀 120/140/160 根，各验证其后 20 根，A 各段收益约 1.71%、3.41%、0.40%。每段均重新调用相同候选/评分规则，窗口之间不重叠、后续可使用已发生历史；这些段并非连续复利，也与主报告最终检验存在时间重叠，不能当作额外独立市场样本重复统计。少于所需历史时明确显示不足；不可行窗口保存错误，不计为零收益。

## 使用及复算

桌面自适应模式新增「成交回放周期」，可选真实 `1h` 或 `15m`；原周期模式保留为兼容选择并明确标注 OHLC 情景。细周期必须严格小于且整除 ATR 周期；请求最多 100000 根。完整成交快照随 JSON 导出。小时线也有 OHLC 内部顺序不确定，仍分别运行 O-H-L-C / O-L-H-C 及普通/双倍成本情景。

联网重新取数（数据更新可能改变结果）：

```bash
CARGO_TARGET_DIR=target cargo run --locked --offline -- \
  --capital 663 --equity 663 --risk-pct 15 --grids 16 \
  --live --mode atr --algorithm adaptive --history-bars 180 \
  --replay-interval 1h --proxy-url http://127.0.0.1:7890 --json
```

用已保存数据离线复算：

```bash
CARGO_TARGET_DIR=target cargo run --locked --offline -- \
  --capital 663 --equity 663 --risk-pct 15 --grids 16 --price 82236.84 \
  --mode atr --algorithm adaptive --interval 1d \
  --candles docs/risk-replay-btc-daily.csv \
  --replay-interval 1h --replay-candles docs/risk-replay-btc-hourly.csv \
  --step-size 0.00001000 --min-notional 5 --json
```

聚合不符、缺根、未覆盖全区间、CSV 错误或分页失败均明确失败，不退回日线。规则仍使用本次快照，历史交易所规则、盘口、限价排队与部分成交未建模。

参考：[币安公开 K 线接口](https://developers.binance.com/en/docs/catalog/core-trading-spot-trading/api/rest-api/market)、[Freqtrade 细周期回测与限制](https://www.freqtrade.io/en/stable/backtesting/)、[未来数据检查](https://www.freqtrade.io/en/stable/lookahead-analysis/)。

# 趋势底仓网格 A/B 实验

以下结果记录首次实验的原风险及日线成交口径。后续已将压力损失纳入硬预算并增加小时线回放，当前方法与结果见 [压力预算与回放验证](risk-replay-validation.md)；不要把本文旧数字当作新版重新计算结果。

## 实现前失败清单与验收约定

- 尾部价格泄漏：趋势信号仅取每段之前 60 根收盘；改变最终检验不能改变信号、发展结果或选参。
- 过拟合：A 沿用原发展段选参；B 共用 A 的价格、数量、投入、SL/TP，不搜索底仓比例、不根据最终收益换策略。
- 隐性加仓：上涨信号为 SMA20 > SMA60 且最后收盘 > SMA60；只把初始卖格中最高的半数（向下取整）锁为底仓，不增购、不动费用储备或闲置资金。
- 非上涨误激活：信号不满足时 B 必须逐字段等于 A；底仓槽位不再参与买卖。
- 浮亏遗漏：底仓逐点计入可清算权益；SL、TP 和期末均出售底仓并扣成本，跳空止损沿用更差开盘。
- 不公平基准：同额买入持有须给出净收益、回撤、双倍成本和费用，包含闲置现金；它不使用网格止损，风险敞口不同。
- 只展示有利样本：合成上涨、震荡、下跌、跳空均经真实 CLI 验收；合成数据只证明行为，不证明投资优势。
- 桌面兼容：旧 JSON 无实验字段仍可解码；新 JSON 与文本及桌面显示 A/B 和收益差。复制参数仍属于 A；B 需要独立底仓管理，不能直接当作币安静态网格参数。

## 方法来源

[币安 Trailing Up](https://www.binance.com/en-BH/support/faq/detail/3d987afd7906495cb4d997eccb8515bf) 通过上移区间适应上涨；[Dynamic Grid Trading 原论文](https://arxiv.org/abs/2506.11921) 研究动态重置。两者启发趋势适应方向，本实验未复刻其算法或引用其收益作为项目证据。

B 是较小范围的趋势底仓混合策略，保留初始持仓以减少上涨途中提前卖出。它可能损失震荡套利机会，并在冲高回落时承担更大库存回撤。预先固定规则后观察独立时段，不能保证优于 A 或买入持有。

## 2026-10-19 真实公开日线结果

固定最多投入/账户资产 663 USDT、风险 15%、16 格、等比、ATR(14)、区间基准 3 ATR、每边手续费 0.1% + 滑点 0.05%。A 只用发展段选择宽度；B 共用 A 的每段方案。下表日期为 UTC 开盘日期，最后一列持有基准没有网格止损。

| 样本 | 最终检验 | A 净收益 | B 净收益 | B−A 百分点 | 买入持有 |
| --- | --- | --- | --- | --- | --- |
| BTCUSDT-180 | 2026-09-13 至 2026-10-18 | 4.62% | 3.57% | -1.05 | 5.84% |
| ETHUSDT-180 | 2026-09-13 至 2026-10-18 | 0.83% | -0.31% | -1.14 | -4.84% |
| BTCUSDT-360 | 2026-08-08 至 2026-10-18 | 2.03% | 2.78% | +0.75 | 25.90% |

BTC 180 根与截图复现一致：A 回撤 2.88%，B 回撤 2.88%，买入持有回撤 8.56%；双倍成本收益依次为 3.97%、3.17%、5.53%。保留最高卖格库存减少了交易次数（29 降至 17），这一段损失的震荡套利收益大于底仓增益。B 在 BTC 360 根检验有改善，但仍落后持有；ETH 180 根 B 更差。不能据此宣称 B 更优秀，保留实验而不自动启用。

BTC、ETH 的 1000 根历史在相同固定 16 格、资金与交易约束下均无可行发展候选，未放松约束以取得结果。不同历史长度的最终检验长度不同，不能横向比较绝对收益。B 是看到截图后设计的回顾性实验，不能把这段历史当作新策略完全未见的前瞻证据。

可审计摘要在 [trend-core-ab-results.json](trend-core-ab-results.json)，含行情时间、规则快照、CSV 哈希、发展段和最终检验完整指标。三个 CSV 保存实际公开 OHLC；完整原始方案及同批行情保存在本机 `target/experiments/trend-core/`（构建目录不提交）。

离线复算截图同段（现价只影响当前规划，历史指标从 CSV 前缀计算）：

```bash
CARGO_TARGET_DIR=target cargo run --locked --offline -- \
  --algorithm adaptive --mode atr --candles docs/trend-core-btcusdt-180.csv \
  --capital 663 --equity 663 --risk-pct 15 --grids 16 \
  --price 82682.01 --tick-size 0.01 --step-size 0.00001 \
  --min-notional 5 --min-qty 0.00001 --json
```

更换 CSV 时需同步对应交易对的现价、规则与精度；联网可使用 `--live --history-bars 180 --proxy-url http://127.0.0.1:7890` 取代 `--candles`，新的收盘数据可能改变结果。无需新增开关，自适应结果自动含 `optimization.holdout.ab_test`，发展段也保存同类对照。经典模式保持原输出。
